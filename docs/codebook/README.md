# Coding materials

This directory contains the human annotation materials for the Salem Historical
Evidence Chain pilot.

- [`salem-codebook.md`](salem-codebook.md) defines units, fields, controlled
  values, evidence rules, and adjudication procedures.
- [`human-coding-form.md`](human-coding-form.md) is the parallel form completed
  independently by human coders.

Current working versions:

- Codebook: `SAL-CB-0.3`
- Human coding form: `SAL-HUMAN-CODING-FORM-1.0`

The form is implementation-neutral and can be mapped to Airtable, REDCap, or a
relational database. The codebook is authoritative if a form label is
ambiguous.
